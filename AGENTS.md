# AGENTS.md

ИИ-помощник ФГУП «ДИД»: веб-приложение на FastAPI для работы с внутренними
документами — закупки, тендеры, юридические документы, обезличивание.

## Команды

Активировать окружение: `venv\Scripts\Activate.ps1` (Windows).

```powershell
# Запуск
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload

# Проверки перед коммитом (обе должны проходить)
python -m pytest -q
ruff check .

# Установка зависимостей
pip install -r requirements.txt
pip install -r requirements-dev.txt   # + pytest, pytest-asyncio, httpx, ruff
```

## Структура

| Путь | Назначение |
| --- | --- |
| `main.py` | Сборка приложения: подключение роутеров, middleware, lifespan |
| `config.py` | Чтение `.env`, пути, режимы подсистем. Импортируется при старте |
| `core/` | Общее: авторизация, LLM-клиент, логи, guard-промптов, разбор ошибок LLM |
| `economist/` | Модуль «Экономист»: интеграция с n8n |
| `lawyer/` | Юридический модуль: RAG, поиск, обработка документов |
| `procurement/` | Закупки: роутер, парсер, кэш |
| `tenders/` | Тендеры: роутер, валидаторы, парсер, кэш |
| `secretary/` | Секретарь, обезличивание (пакет `anomizer` внутри — сторонний) |
| `tests/` | pytest; настройки изоляции — в `tests/conftest.py` |
| `scripts/` | Служебные и диагностические скрипты, `manage_users.py` |
| `deploy/` | systemd-юниты и файлы развёртывания |

## Обязательные правила

**Проверяй перед тем, как отвечать.** После правок запускай `python -m pytest -q`
и `ruff check .`. Обе команды обязаны быть зелёными.

**Конфигурация только через `config.py`.** Не читай `os.environ` напрямую в
роутерах — все параметры уже разобраны в `config.py` при импорте. Переменные
читаются на этапе импорта, поэтому тест, меняющий `os.environ` после импорта
модуля, ничего не даст.

**Тесты не ходят в сеть и не трогают рабочие данные.** Тесты запускаются с
`AUTH_ENABLED=false`, с `USERS_FILE`/`SETTINGS_FILE`/`CHROMA_PERSIST_DIR` во
временном каталоге и `WHISPER_PRELOAD=false`. Новый тест, обращающийся к
внешнему API или к настоящему `chroma_data`, должен использовать фикстуру
`offline_settings` или мок. Причина: `tests/conftest.py` выставляет переменные
до `from main import app`, иначе приложение поднимет настоящие подсистемы.

**HTTP-клиент — через ASGI.** Фикстура `client` использует
`httpx.ASGITransport`; lifespan не выполняется, поэтому сетевые подсистемы не
стартуют. Не поднимай `TestClient` ради одного теста.

**`secretary/anomizer/src/anomizer/` — сторонний пакет.** Правки вноси точечно,
по совместимости с исходной логикой. В `ruff.toml` для него отключены `F401`,
`B904`, `B007`, `ARG`, `SIM`: импорты и имена циклов там несут смысл.

**Секреты не в коде.** Ключи DeepSeek, GigaChat, GigaChat-Embedding и
`AUTH_SECRET` читаются из `.env`. В репозитории лежит только `.env.example`;
реальный `.env` в `.gitignore`. В `opencode.json` ключ должен быть
`{env:DEEPSEEK_API_KEY}`, а не строкой.

## Настройки окружения

Основные переменные (полный список с комментариями — в `.env.example`):

| Переменная | Смысл |
| --- | --- |
| `AUTH_ENABLED` | Вход по логину и паролю. По умолчанию включён |
| `AUTH_SECRET` | Ключ подписи cookie сессии. Не задан — генерируется и хранится в `users.json` |
| `AUTH_COOKIE_SECURE` | `true` только вместе с HTTPS, иначе пароль идёт открытым текстом |
| `EMBEDDING_PROVIDER` | `gigachat`, `openai` или локальная модель |
| `WHISPER_PRELOAD` | Предзагрузка модели транскрипции при старте. Занимает время и память |
| `CHROMA_PERSIST_DIR` | Каталог векторного хранилища |

Если `AUTH_ENABLED=true`, а `users.json` пуст, все страницы отдают 503 с
подсказкой. Первого администратора создаёт
`python -m scripts.manage_users add <логин> --admin`. Логины — латиница,
1–64 символа `[a-z0-9._-]`.

## Известные особенности

- **`chroma_data` не переживает два процесса.** Два экземпляра uvicorn на одном
  каталоге приведут к ошибке доступа к SQLite. Запускай один.
- **`--reload` перезапускает приложение целиком.** При этом пересоздаётся
  клиент Chroma и заново читается конфигурация.
- **Lifespan тяжёлый.** Он поднимает Whisper и модель эмбеддингов, если
  соответствующие флаги включены. Тесты его не выполняют намеренно.
- **Настройки читаются с внешних сервисов.** `core/settings_router.py` ходит в
  сеть за моделями и курсами валют — в тестах это заглушено.
- **Роутеры монтируются с префиксами.** Путь в браузере и `app.routes` различаются:
  проверяй `app.openapi()`, а не догадывайся.

## Стиль

Python 3.12, `from __future__ import annotations`, русский язык в комментариях,
docstrings и пользовательских сообщениях. Типизация — на существующем уровне
файла: не вводи `list[str]` вместо `List[str]` в старом коде без нужды (правила
`UP006/UP007/UP035` отключены осознанно). Линтер: `ruff.toml`, длина строки 100.
